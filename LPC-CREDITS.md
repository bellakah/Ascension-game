# LPC asset credits

Ascension Game uses character artwork from the Universal LPC Spritesheet Character Generator:
https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator

Current prototype layers:
- `spritesheets/body/bodies/male/walk.png`
- `spritesheets/torso/chainmail/male/walk.png`

The LPC repository contains artwork under multiple open licenses (including CC0, CC-BY, CC-BY-SA, OGA-BY and GPL depending on the selected asset). Attribution and license details for each selected layer must be preserved when assets are bundled for release.

Project credits/licensing reference:
https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator#licensing-and-attribution-credits

Note: this first integration loads the two LPC walk layers from the upstream repository at runtime. Before a production release, pin/copy the selected assets into this repository together with their generated exact credits manifest.
