# LPC asset credits

Ascension Game currently loads prototype character layers from the Universal LPC Spritesheet Character Generator:
https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator

Current Guerreiro prototype layers:

- male body: `spritesheets/body/bodies/male/`
- human male head: `spritesheets/head/heads/human/male/`
- chainmail: `spritesheets/torso/chainmail/male/`
- bedhead hair: `spritesheets/hair/bedhead/adult/`
- male pants: `spritesheets/legs/pants/male/`
- basic male boots: `spritesheets/feet/boots/basic/male/`
- steel arming sword: `spritesheets/weapon/sword/arming/`

Animations currently used: `idle`, `walk` and `halfslash`.

The Universal LPC project contains assets under multiple open licenses. Exact attribution/license data for every layer must be preserved before distributing bundled production assets. The arming sword definition credits ElizaWy, with walk/down work by JaidynReiman, under OGA-BY 3.0.

For this prototype the PNGs are loaded from the upstream repository at runtime. Before a production release, pin/copy the selected assets locally and preserve the exact generated credits manifest.
